# Forma — твоё пространство для фокуса

Менеджер задач в эстетике Notion: спокойная типографика, светлая рабочая область и мягкие зелёные акценты. Тестовое задание, выполненное с помощью ChatGPT / Codex.

## Запуск

Требуется Node.js 22.18+ (или Node.js 24+) и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite.

```bash
npm test         # проверки хранения, валидации и фильтрации
npm run build    # проверка TypeScript и production-сборка
npm run preview  # просмотр сборки
```

## Возможности

- Календарь месяца с отдельными блоками дней, неделя начинается с понедельника.
- Переключение месяцев, быстрый выбор месяца и возврат к сегодняшней дате.
- Панель выбранного дня: добавление, выполнение, редактирование и удаление задач.
- Дедлайн до конца выбранного дня и перенос задачи через изменение даты.
- Разделы «Просрочено» и «Без даты»; старые задачи остаются без даты.
- Приоритеты, поиск по названию и фильтры статуса.
- Счётчики месяца и прогресс выполнения.
- Отмена последнего удаления до закрытия уведомления или следующего удаления.
- Сохранение в localStorage, совместимость с предыдущими версиями.
- На телефоне — компактная сетка со счётчиками и крупные карточки выбранного дня.
- Сообщения об ошибках чтения или записи хранилища.

## Стек и структура

React 19, TypeScript, Vite, Lucide React, CSS.

- `src/App.tsx` — рабочее пространство, фильтры, поиск и формы.
- `src/components/TaskItem.tsx` — строка задачи и редактирование.
- `src/hooks/useTasks.ts` — состояние и сохранение.
- `src/utils/tasks.ts` — валидация сохранённых данных и фильтрация.
- `src/utils/calendar.ts` — локальные даты и сетка месяца.
- `src/utils/*.test.ts` — тесты хранения, фильтров и календаря.
- `src/types/task.ts` — модель задачи.
- `src/styles.css` — дизайн и адаптивность.
- `legacy/` — резервная копия исходной HTML-версии, не входит в сборку.

## Данные

Приложение не требует регистрации или сервера. Задачи сохраняются только в текущем браузере для текущего адреса сайта. Очистка данных сайта удалит список. Между устройствами и вкладками автоматической синхронизации нет. При ошибке записи изменения остаются в памяти, а интерфейс показывает предупреждение. Шрифт Manrope загружается из Google Fonts; если сеть недоступна, используется системный шрифт.

## Публикация

После `npm run build` папка `dist/` готова для статического хостинга. В Vite установлен относительный `base`, поэтому сборка поддерживает размещение в подпапке GitHub Pages. Для GitHub Pages используйте workflow `.github/workflows/deploy.yml` и выберите источник Pages: GitHub Actions. Workflow запускается вручную или при push в main.

## Ручная проверка перед сдачей

1. Добавить задачу, изменить название и приоритет.
2. Выбрать день следующего месяца, добавить задачу, перенести её в другой день.
3. Отметить выполненной и проверить фильтры и прогресс.
4. Перезагрузить страницу и убедиться, что состояние сохранилось.
5. Найти задачу по части названия, проверить фильтры.
6. Удалить задачу, отменить удаление.
7. Проверить пустой ввод, длинное название и текст с HTML-тегами.
8. Проверить экран телефона и управление Tab / Enter / Escape.
